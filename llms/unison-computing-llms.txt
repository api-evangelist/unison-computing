# Unison Computing

> Unison Computing, PBC is the public benefit corporation behind the Unison programming language, Unison Cloud, and Unison Share. Unison is a statically-typed functional language with content-addressed code; Unison Cloud deploys Unison services with a function call; Unison Share is the community code host and package registry, and also the OAuth2/OIDC authentication server for UCM and Unison Cloud.

Generated by API Evangelist from the provider's public surface on 2026-07-21 (method: generated — the provider publishes no /llms.txt, but does publish official LLM support files, linked below).
